# 05 — Fotos

Fontes trabalhadas:
- Planespotters.
- JetPhotos via JetAPI quando disponível.

A galeria foi corrigida para usar uma foto grande por vez, com setas e indicadores, em vez de empilhar miniaturas verticalmente. Quando uma fonte não fornece imagem utilizável, o sistema deve indicar indisponibilidade em vez de fabricar/repetir fotos.
