# 06 — Origem, destino e linhas

A origem/destino é enriquecida pelo callsign usando provedores externos de rota. O radar ao vivo não deve inventar origem/destino quando a fonte não os fornece.

As linhas desenhadas no mapa incluem o histórico disponível e segmentos de rota quando as coordenadas de origem/destino estão disponíveis.
