# 08 — Meu Voo

Conceito inspirado no myFlightradar24.

## Objetivo
Permitir ao usuário logado manter um diário/arquivo pessoal de voos.

Campos planejados:
- número do voo;
- data;
- origem;
- destino;
- companhia;
- aeronave/registro quando conhecido;
- assento, se o usuário quiser guardar;
- status;
- histórico pessoal.

A área deve ser privada por usuário e vinculada à conta autenticada.
