# 06 — Pistas e detalhes do aeroporto

A página do aeroporto deve mostrar:
- número/designação das pistas;
- comprimento;
- superfície;
- status operacional quando disponível;
- diagrama/mapa da pista quando houver fonte adequada;
- terminais;
- elevação;
- cidade;
- país;
- IATA;
- ICAO;
- operador.

O layout visual desejado foi definido a partir das referências enviadas pelo usuário e do conceito de painel de aeroporto do Flightradar24.
