# 13 — Checklist antes de lançar online

- [ ] Login/cadastro testados.
- [ ] `.env` de produção configurado sem expor segredos.
- [ ] Banco de dados funcionando.
- [ ] OpenSky funcionando dentro dos limites da fonte.
- [ ] Aeroportos mundiais carregando sem travar o mapa.
- [ ] Satélite/camadas funcionando.
- [ ] Filtros voo/solo/aposentadas funcionando.
- [ ] Origem/destino testados.
- [ ] Linhas de rota testadas.
- [ ] Fotos testadas.
- [ ] ATC testado e fontes que permitem incorporação confirmadas.
- [ ] Câmeras testadas e fontes de terceiros confirmadas.
- [ ] Desktop e celular testados.
- [ ] HTTPS e domínio configurados.
