# 11 — Rotas e ações do voo

Ações consolidadas no painel:
- Rota: exibe origem → aeronave → destino quando coordenadas existem.
- Seguir: centraliza o mapa na aeronave selecionada durante as atualizações.
- Informações: mostra/esconde informações extras.
- Modo 3D: aproxima o mapa.
- Compartilhar: usa compartilhamento do navegador ou clipboard quando disponível.

A rota deve usar dados reais de origem/destino. Sem dados, não fabricar aeroporto.
