# 15 — Fontes e referências técnicas

- OpenSky Network — estados ADS-B/Mode-S.
- OurAirports — base mundial de aeroportos.
- ADSBDB — dados de aeronaves e registros.
- HexDB — rota/identificação auxiliar.
- SkyLink/RapidAPI — ano de fabricação e metadados, quando configurado.
- Planespotters — fotos, sujeito a disponibilidade/403.
- JetPhotos/JetAPI — fotos alternativas.
- Aviation Weather Center — METAR/TAF e dados meteorológicos.
- Flightradar24 — referência de UX, painéis de aeroporto, busca e dados públicos.
- myFlightradar24 — referência para a área pessoal “Meu Voo”.
