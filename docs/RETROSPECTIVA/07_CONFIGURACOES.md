# 07 — Engrenagem / Configurações

O menu ⚙ aplica e salva preferências como:
- estilo do mapa;
- brilho;
- linha dia/noite;
- mostrar aeroportos;
- rótulos/nome dos voos;
- contador;
- filtros rápidos;
- atualização automática;
- animações reduzidas;
- aeronaves em voo;
- aeronaves em solo;
- aeronaves aposentadas.
