# 10 — Logos das companhias

No painel de voos/aeroportos:
- identificar a companhia pelo callsign/flight number quando possível;
- mostrar logo ao lado da companhia;
- usar fallback textual quando a logo não estiver disponível;
- não usar logo de uma companhia diferente apenas para preencher a interface.

As referências visuais enviadas mostram LATAM, GOL, Azul, Copa, Lufthansa, Qatar, United, TAP e outras companhias nos cartões de voo.
